# 个人画像 (Personal Profile)

一款 **Local-First（本地优先）** 的个人学术/求职档案管理、智能文件填表与去 AI 味简历/文书生成桌面应用（基于 Electron + React 19 + TypeScript + Ant Design 6 构建）。

> 🔒 **隐私安全声明**：所有个人资料、证明扫描件与历史快照均存储在您本地电脑（默认 `%APPDATA%/个人画像`），API Key 采用操作系统级 `safeStorage`（Windows DPAPI）加密存储，身份证号等敏感字段默认打码且绝不发送给在线大模型。

---

## ✨ 核心功能亮点

### 1. 📄 智能文件填表（检索资料与文献库 + 未知项追问记忆 + 证件照自动嵌入）
- **上传即填**：支持直接拖入 `.docx`（Word 报名表/申请表/登记表）及 `.txt` / `.md` / `.csv` 文件，AI 自动解析表格网格结构与填空项，检索您的基本信息、科研论文文献库、获奖经历与问答记忆库进行精准填写。
- **严禁胡编乱造（未知项追问并永久记忆）**：资料库中未找到的栏目（如未录入的学号、辅导员、指导老师或特定主观问答）自动标记为待补充并向您提问；您填写回答后，系统自动将其永久记入基本信息自定义字段或问答记忆库，下次填表自动复用。
- **📷 一寸证件照自动嵌入**：自动识别 Word 表格中的「照片 / 一寸免冠照片 / 贴照片处」单元格，将您的个人证件照直接按标准一寸比例嵌入对应单元格（`<w:drawing>`）。
- **灵活保存**：支持选择**生成填写后的新文件**（默认保存在原文件同一文件夹下 `原文件名_已填写.docx`）或**直接在原文件上覆盖保存**。
- **后台持续运行**：支持全后台解析填表与跨页面完成提醒，切页查阅资料不中断。

### 2. 🤖 多模态 AI 整理导入与冲突/重复智能诊断
- **多格式提取**：支持拖入 PDF 简历/成绩单、图片证书扫描件（支持视觉模型 OCR）、Word 文档或直接口述经历，AI 自动拆解归类并挂载原文件为证明附件。
- **冲突与重复诊断引擎**：
  - 自动区分 **「成绩计算方式/分制不同」**（如四分制 `3.85/4.0` vs 五分制 vs 百分制 `91.5/100`）与 **「同分制不同学期成绩更新」**；
  - 支持在导入审核页、总览页与分类页**一键并列保留双分制**、**采用最新成绩**、**无损合并重复条目及其物理附件**或**一键修复起止时间倒置**。

### 3. ✍️ 真人语感文案生成 + 针对性提意见改写
- **彻底告别八股套路**：内置反 AI 腔规则，严禁“赋能、抓手、闭环”等黑话，严禁“在学习方面…在科研方面…在实践方面…综上所述”的机械排比结构。
- **💬 指哪改哪交互式打磨**：支持对已生成文本直接提出修改意见（内置 `🗣️ 去 AI 味/更像真人说话`、`🚫 打破“在XX方面”死板套路`、`🎤 改为自然面试口语`、`🔬 突出具体经历与数据细节`、`✂️ 删减客套话`、`📉 精简压缩篇幅` 快捷标签），并提供多版本历史栈随时 **「↩️ 退回上一版」**。

### 4. 📑 去 AI 模板感简历导出（PDF / Word）与证明材料规范打包
- **三种高质感主题**：经典干练黑白风（默认，最接近真人手写 LaTeX/Word 高分简历）、现代深蓝、学术衬线风。
- **一页纸自适应紧凑调节**：支持 `⚡ 紧凑一页纸（防超页）`、`📄 标准适中`、`🌿 舒展充实` 三档实时预览调节。
- **模块顺序自由调整**：支持上下移动简历各分类顺序，并提供 `🎓 科研/保研优先排序` 与 `💼 求职/实习优先排序` 一键预设。
- **🧹 简历文字一键去 AI 味**：自动扫描库内经历描述中的浮夸套话，提供前后对比预览并一键替换为平实干练表达。
- **📦 证明材料按规范重命名打包**：自动将勾选条目的证书/证明原件按 `01_分类_标题.pdf` 规范重命名，并生成《`00_证明材料目录清单.txt`》打包为 ZIP，直接用于奖学金、夏令营或资格审查上交。

### 5. 📌 网申置顶悬浮小窗 + 🕒 历史快照「时光机」
- **置顶悬浮小窗**：在「快速填表」页一键切换为 400px 宽度的右侧置顶小窗，边看浏览器网申系统边点击复制字段，或粘贴网申表单截图由 AI 批量匹配答案。
- **多重防丢保障**：编辑表单 600ms 自动防抖落盘、跨页面状态常驻与 `localStorage` 草稿恢复、后台自动保存最近 **20 个历史快照版本**，支持在「导出与备份」页随时通过**历史快照时光机**一键可视化回滚。

## 🚀 快速开始

### 环境要求
- Node.js `>= 20`
- Windows 10 / 11（支持 macOS / Linux 开发运行）

### 安装依赖
```bash
npm install
```

### 启动开发模式
```bash
npm run dev
```

### 运行类型检查与单元测试
```bash
npm run typecheck
npm test
```

### 打包 Windows 桌面安装包
```bash
npm run dist
```
打包完成后产物位于 `dist/` 目录：
- 免安装版：`dist/win-unpacked/PersonalProfile.exe`
- 安装程序：`dist/个人画像-Setup-0.1.0.exe`

---

## ⚙️ 模型配置说明

首次启动后前往左侧菜单 **「设置」**：
1. 选择预设服务商（支持 **DeepSeek**、**通义千问 DashScope**、**Kimi Moonshot**、**智谱 GLM**、**OpenAI** 或任意兼容 OpenAI 接口的自定义服务商）。
2. 填入 API Key 后，系统会自动调用 `/models` 接口识别可用模型并推荐文本模型（如 `deepseek-chat`、`qwen-plus`）与视觉模型（如 `deepseek-vl2`、`qwen-vl-max`）。
3. 点击 **「测试连接」** 验证通过后即可使用全部 AI 功能。

## 📁 目录结构

```text
├── src/
│   ├── main/                 # Electron 主进程
│   │   ├── services/
│   │   │   ├── ai/           # OpenAI 兼容客户端、结构化提取、去 AI 味提示词与流式生成
│   │   │   ├── export/       # 简历模型、HTML/PDF 渲染、Word (.docx) 生成、证明材料与备份打包
│   │   │   ├── docfill.ts    # 智能文件填表（.docx/.txt 解析、文献库检索、证件照嵌入与回写）
│   │   │   ├── parse.ts      # 本地文档文本提取
│   │   │   ├── settings.ts   # DPAPI 加密配置与数据目录统一管理
│   │   │   └── store.ts      # 本地 JSON 原子存储、字段无损合并与历史快照时光机
│   │   ├── index.ts          # 窗口生命周期管理
│   │   └── ipc.ts            # IPC 处理器注册
│   ├── preload/              # 预加载安全桥接 (contextBridge)
│   ├── renderer/             # React 19 + Ant Design 6 渲染进程界面
│   └── shared/               # 跨进程共享类型、内置分类 Schema 与冲突/重复诊断引擎
└── tests/                    # Vitest 单元测试套件（存储、AI 解析、文档填表与简历导出）
```
